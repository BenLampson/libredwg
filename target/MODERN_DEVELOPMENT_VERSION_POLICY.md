# 现代 Alpha/Beta DWG 的 Stream 处理策略

## 范围决定

以下 8 个版本是 AutoCAD 开发过程中的 Alpha、Beta 或候选格式，不是当前
项目要求支持的正式发布格式：

| LibreDWG 版本 | 文件标识 |
| --- | --- |
| `R_2000b` | `AC1500` |
| `R_2004a` | `AC402a` |
| `R_2004c` | `AC1018`，内部版本 `0x18` |
| `R_2007a` | `AC701a` |
| `R_2007b` | `AC1021`，内部版本 `0x1a` |
| `R_2010b` | `AC1024`，内部版本 `0x1c` |
| `R_2013b` | `AC1027`，内部版本 `0x1e` |
| `R_2018b` | `AC1032`，内部版本 `0x20` |

Stream API 必须识别这些版本，但不尝试读取对象。`dwg_stream_file` 和
`dwg_stream_file_ex` 必须直接返回 `DWG_ERR_NOTYETSUPPORTED`。

## 强制行为

- 不调用 `dwg_read_file`，不做阻塞式回退；
- 不触发对象回调；
- 不触发解码对象回调；
- 不触发对象解码错误回调；
- 无论是否设置 `DWG_STREAM_F_NO_FULL_FALLBACK`，结果都相同；
- 对共享正式版魔数的格式，必须先读取内部版本字段再判定，不能只看前
  6 个字节；
- 未知魔数继续返回 `DWG_ERR_INVALIDDWG`，不得与已知但不支持混淆。

## 正式版目标

与上述开发版对应的正式格式仍在支持范围内：

```text
R_2000, R_2004, R_2007, R_2010, R_2013, R_2018
```

项目提供的 20 个有效业务文件覆盖这些正式格式，已全部通过 C 阻塞式与
纯 Stream 严格对齐，共 6,347,881 个对象、零 Stream 单对象解码错误，且
全部 `full=0`。逐文件结果见 `result.md`。

`R_2004b` 不在本次排除列表中。它已有外部真实 AC402b 文件严格对齐证据，
继续保留现有 Stream 支持。

## 验证

`test/unit-testing/stream_test.c` 为可执行合同。它使用 C writer 生成上述
8 个精确版本，先确认阻塞式读取识别出的版本正确，再验证新旧 Stream API
均返回 `DWG_ERR_NOTYETSUPPORTED`，所有回调计数为 0，并且没有完整读取回退。

本策略把无法取得真实历史文件的内部开发格式从产品支持目标中排除，因此
不再要求继续搜索这些文件来判定当前目标完成。历史检索过程仍保留在
`target/modern-beta-source-audit.txt`，仅作为决策依据和追溯记录。
