# Independent AC1003 fixtures

These eight entity fixtures come from the BSD-2-Clause licensed
`michal-josef-spacek/CAD-Format-DWG-AC1003` repository at commit
`6eab07d45cf637d86e482f9cf28b4137af5f1f1b`:

https://github.com/michal-josef-spacek/CAD-Format-DWG-AC1003

The upstream project identifies the files as AutoCAD 2.60 DWG (`AC1003`),
which LibreDWG maps to `R_2_6`. The files retain their upstream names and
bytes. The upstream BSD-2-Clause license is reproduced in `LICENSE`.
